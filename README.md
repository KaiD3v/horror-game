# Santa Clara: terror na serra, 1974

É uma demo em Godot 4.7, com assets N64 gerados por scripts Blender e Python sem interface.

- **Jogo:** `godot_demo/`. A cena inicial é `scenes/menu.tscn`.
- **Pipeline:** `tools/`. Gera os modelos, as texturas, os sons e a fonte do jogo.
- **Documentação:** `docs/`.
  - Comece por [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md): pastas, sistemas reutilizáveis e como criar NPC, inimigo, interior e nota.
  - O mundo está em [`docs/VILAREJO.md`](docs/VILAREJO.md), [`docs/ENFERMEIRA.md`](docs/ENFERMEIRA.md) e [`docs/CENARIOS.md`](docs/CENARIOS.md).
  - As pendências de arte estão em [`docs/TODO_ARTE.md`](docs/TODO_ARTE.md).
